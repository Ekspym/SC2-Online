# SC2 Online

Soulcalibur II (Xbox, USA) online with rollback netcode. An unofficial fan project, not made or supported by Bandai Namco.

**Download:** the latest release on the right (`sc2_online.zip`).

You need Windows 10 / 11 (64-bit) and your own Soulcalibur II (USA) Xbox disc as an image (.iso). No code or data of the
game is in the download: the launcher builds the game from your own disc image on your PC (about 4-5 minutes, once).

The game program is free software under the GPL-3.0; its source and its authors: https://github.com/Ekspym/sc2-online-source
